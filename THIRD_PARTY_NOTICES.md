# Third party notices

Enclave is built on open source software. This file lists the parts of the browser image
(what runs each profile) and the server side. The npm packages inside the Windows app and the
phone app are listed, with their full license texts, in `THIRD_PARTY_LICENSES.txt`, generated by
`node scripts/gen-notices.mjs` (run it after changing dependencies). Both files ship with the app,
in the `notices` folder of the install directory. Electron's own license and Chromium's
(`LICENSE.electron.txt`, `LICENSES.chromium.html`) are installed beside `Enclave.exe`.
